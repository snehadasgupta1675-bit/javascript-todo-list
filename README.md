# JavaScript To-Do List

An interactive client-side To-Do List application built using HTML, CSS, and JavaScript.

## Features

* Create, read, update, and delete tasks
* All, Active, and Completed filters
* Local Storage data persistence
* Dynamic DOM manipulation
* Event delegation
* Enter-key support
* Responsive design

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser Local Storage

## How to Use

1. Enter a task in the input box.
2. Click **Add** or press **Enter**.
3. Use the checkbox to mark a task as completed.
4. Use **All, Active, or Completed** to filter tasks.
5. Click **Delete** to remove a task.
6. Tasks remain saved after refreshing the browser.

## Project Purpose

This project was developed as part of a Web Development internship task to practice JavaScript logic, DOM manipulation, event handling, CRUD operations, and client-side data persistence.
